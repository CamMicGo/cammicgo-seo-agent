# CamMicGo browser extension — early prototype

Desktop Chrome/Edge: open chrome://extensions, enable Developer mode, Load unpacked and choose this extension directory. Open a YouTube watch page and click the extension.

The extension currently inspects browser video text tracks when available. It does **not** yet fetch all YouTube subtitle tracks, authenticate to CamMicGo, poll a task queue or deliver results to Claude. It does not transmit cookies. This is an early local test, not a complete product.

Standard Chrome for Android does not install desktop Chrome extensions. Firefox and mobile support require separate compatibility work. Do not install untrusted alternative browsers to bypass this limitation.
